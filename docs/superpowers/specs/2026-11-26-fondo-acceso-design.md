# Fondo de acceso

Sustituir el círculo de la pantalla inicial de acceso por una composición de bandas moradas suaves sobre el fondo oscuro existente. Las bandas se desplazan lentamente sin interferir con los controles, el texto ni el área segura móvil. Con movimiento reducido se muestra la composición estática. La decoración se oculta a lectores de pantalla y no altera el inicio de sesión, registro o acceso invitado.
